Frequently asked questions

The practical details.

Still deciding whether School Day Grid fits your household? Start here.

What kinds of schedules does it support?

Any repeating sequence you define—from A/B days to Day 1–6 and beyond. The sequence advances only on school days.

Does it require Home Assistant?

No. School Day Grid is a standalone web application. Home Assistant and MQTT are optional integrations.

Where is my calendar data stored?

In a local SQLite database controlled by the person hosting the application. Full database backups and portable profile exports are built in.

Can I import my district’s calendar?

Yes. Upload an ICS file or subscribe to an ICS URL. School Day Grid presents likely no-school dates for review before they are added.

Can family members see the schedule?

Yes. Share a read-only web link or a private ICS subscription. Tokens can be rotated if a link ever needs to be revoked.

Is School Day Grid free?

Yes. It is open-source software with no subscription. You provide the computer or hosting environment where it runs.
