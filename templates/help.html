Calendar help

These are optional advanced integrations. They require setup with the outside service before you can use the fields on the calendar page.

Google Calendar sync

  1. Create or choose the Google Calendar where you want this schedule copied.
  2. Follow Google’s instructions to create OAuth access for Calendar and approve permission to edit your calendar.
  3. Find the calendar ID in Google Calendar’s settings, then paste the ID and the temporary access token into School Day Grid.

Google’s Calendar authorization instructions · Google’s OAuth setup guide · Finding a Google calendar ID

Outlook / Microsoft 365 sync

  1. Create or choose the Outlook calendar where you want this schedule copied.
  2. Follow Microsoft’s instructions to register an app and sign in to obtain a temporary access token with Calendars.ReadWrite permission.
  3. Paste the calendar ID and token into School Day Grid.

Microsoft’s step-by-step access-token guide · Microsoft’s calendar permissions guide

Notifications

ntfy: create a topic in the ntfy app or website, enter the ntfy server address (usually https://ntfy.sh) and your topic, then press Send test.

Webhook: use this only if another service has given you a webhook URL. Paste that URL and use Send test; the other service’s documentation explains how its webhook must be configured.

ntfy’s publishing instructions · ntfy mobile-app setup

Sharing and calendar subscriptions

Shareable calendar page is a browser link you can send to someone. Calendar app subscription is for adding the schedule to Google Calendar, Apple Calendar, or Outlook.

Only replace either link if it was shared with the wrong person or you want to stop the old link from working. Replacing a subscription link means anyone who used the old one must subscribe again using the new link.

Check calendar setup

This checks for setup problems such as a missing school-year range, missing cycle days, or an override outside the school year. It does not change your calendar.
