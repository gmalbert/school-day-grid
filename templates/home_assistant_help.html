Connect School Day Grid to Home Assistant

School Day Grid remains the source of truth. Home Assistant can read today’s school-day data, subscribe to the calendar, or—when configured—receive a copied calendar. Choose the smallest connection that meets your need.

Recommended: REST sensors

This is the best choice for dashboard cards, automations, and voice assistants. It requires no Home Assistant token in School Day Grid.

  1. Give the device running School Day Grid a stable LAN address.
  2. Copy home-assistant/school_day_grid.yaml from this project to Home Assistant at /config/packages/school_day_grid.yaml.
  3. Replace each 192.168.1.42 in that file with the School Day Grid host’s fixed IP address or local DNS name.
  4. If packages are not enabled, add homeassistant: packages: !include_dir_named packages to Home Assistant’s configuration.yaml.
  5. Check configuration and restart Home Assistant.

The package creates sensor.school_day_grid_today, sensor.school_day_grid_tomorrow, and sensor.school_day_grid_next_school_day. It refreshes them every five minutes and just after midnight.

Network: Home Assistant must be able to reach http://YOUR-SCHOOL-DAY-GRID-HOST:8088/api/v1/health. Keep port 8088 on your LAN; do not expose it directly to the public internet.

Calendar subscription

For a read-only copy of the full schedule, use the private Calendar app subscription link in Sharing & subscriptions. Add that URL to a Home Assistant calendar integration or another calendar service that Home Assistant already reads. Treat the URL as a password: anyone with it can read the calendar. Replace the subscription link if it is exposed.

MQTT Discovery

Use this only when you already operate an MQTT broker that Home Assistant can use. Add these values to School Day Grid’s .env file, then restart the app:

SDG_MQTT_HOST=192.168.1.10
SDG_MQTT_PORT=1883
SDG_MQTT_USERNAME=your_username
SDG_MQTT_PASSWORD=your_password
SDG_MQTT_DISCOVERY_PREFIX=homeassistant
SDG_MQTT_BASE_TOPIC=school_day_grid

School Day Grid publishes Discovery definitions for Today, Tomorrow, and Next School Day after schedule changes. REST sensors are preferable when the displayed value must update automatically at midnight.

Direct Home Assistant adapter

This optional compatibility adapter lets School Day Grid authenticate to Home Assistant’s API for legacy migration and calendar publishing. Create a long-lived access token in Home Assistant’s user profile, then put the URL and token in School Day Grid’s .env file:

SDG_HA_URL=http://homeassistant.local:8123
SDG_HA_TOKEN=paste_a_long_lived_access_token_here
SDG_VERIFY_SSL=true

Restart School Day Grid after editing the file. The Home Assistant card on the calendar page will change from “Not connected” to show the configured address.

Security: never commit the token, send it in a calendar link, or store it in a shared document. Keep SDG_VERIFY_SSL=true; set it to false only for a trusted self-signed certificate on your private network.

Troubleshooting

  • Open /api/v1/health from Home Assistant’s network first. If it cannot load, solve the host address, port, firewall, or sleep issue before changing YAML.
  • If REST sensors are unavailable after a restart, check Home Assistant’s configuration error log and verify the package path and indentation.
  • If the direct adapter will not authenticate, confirm the URL includes http:// or https://, create a new long-lived token, and restart School Day Grid.
