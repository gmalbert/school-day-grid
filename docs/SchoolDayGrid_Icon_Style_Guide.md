# SchoolDayGrid Icon Style Guide

This document is meant to preserve the visual system used for the SchoolDayGrid special-subject icons so future icons can be generated in the same style.

---

## Purpose

Create app-ready icons for school specials and subject categories that feel consistent with the clean SchoolDayGrid interface.

These icons should:
- feel polished, modern, and friendly
- work well at small UI sizes inside calendar cells
- remain readable at a glance
- have transparent backgrounds
- be delivered as individual PNG files

---

## Core Visual Style

Use a **clean, rounded, glossy vector icon style** with these characteristics:

- **single subject/object per icon**
- **simple silhouette** that reads clearly at small sizes
- **rounded forms** rather than sharp or aggressive geometry
- **dark navy outline** around the icon
- **soft interior shading / glossy highlights**
- **bright but tasteful color palette**
- **no background tile/card**
- **transparent background only**
- **no text or labels inside the icon file**
- **no scene or extra decorative elements** unless they are part of the core concept

This is **not** a comic-book style, hand-drawn style, or flat monochrome outline style.
It should feel like a polished UI asset set.

---

## Output Requirements

For each icon:

- **Format:** PNG
- **Background:** transparent
- **Composition:** centered icon only
- **Canvas:** square, typically 1024×1024 or similar 1:1 ratio
- **One file per icon**
- **No label text**
- **No drop shadow floating outside the icon**
- **No border box, badge, or tile**

---

## Line and Shape Language

- Use **medium-thick dark navy outlines**
- Keep line weight consistent across the set
- Favor **soft corners, rounded terminals, rounded object edges**
- Avoid intricate tiny details that disappear at small size
- Keep each icon visually bold and easy to recognize

Recommended outline feel:
- dark navy / deep blue rather than black
- smooth, uniform perimeter

---

## Rendering Style

The icons should feel like **modern glossy vector stickers** or **premium app icons without a background tile**.

Use:
- soft highlight areas
- mild gradients or tonal shifts
- clean interior fills
- subtle dimensionality

Avoid:
- sketch texture
- watercolor texture
- gritty texture
- photorealism
- 3D scene rendering
- comic inking
- emoji look

---

## Color Approach

Use saturated but controlled colors. Keep each icon associated with a recognizable dominant color.

Suggested subject-color associations:

- **Library / Reading:** blue or teal
- **Music / Chorus:** purple or pink-purple
- **Art / Digital Art:** orange / multicolor accents
- **Technology:** blue
- **PE:** coral / red
- **Science:** green
- **Social Studies / Geography:** yellow-gold and blue-green globe tones
- **Math:** purple
- **World Language:** pink
- **Health / Nurse:** coral or red
- **Cooking / Culinary:** white chef hat with cool gray-blue shading
- **Engineering / Makerspace:** orange + steel / gray
- **Advisory / Guidance / Community:** blue
- **Study Hall:** blue + warm yellow

The palette should stay cheerful and clean, not neon-chaotic.

---

## Composition Rules

- One clear icon concept per file
- Fill most of the canvas without touching the edges
- Center the icon visually
- Leave enough margin for UI use
- If a concept needs two objects, keep them tightly integrated (example: wrench + screwdriver, palette + brush)
- Prefer the simplest object that instantly communicates the subject

---

## Approved Style Formula

When generating future icons, use language like this:

> Create a single app-ready school subject icon in a clean rounded glossy vector style with a transparent background. Use a centered composition, dark navy outline, soft highlights, simple readable shapes, and no text. Keep it consistent with a polished educational UI icon set.

## Naming Convention

Use descriptive file names in lowercase with underscores or simple words. Examples:

- `library_open_book.png`
- `music_note.png`
- `art_palette_brush.png`
- `technology_laptop.png`
- `pe_sneaker.png`
- `science_flask.png`
- `social_studies_globe.png`
- `reading_bookmark.png`
- `math_calculator.png`
- `world_language_chat_bubbles.png`

For alternates:
- `library_stacked_books.png`
- `pe_whistle.png`
- `science_microscope.png`

---

## What to Avoid

Do **not** generate icons that are:
- comic-book-like
- heavily detailed illustrations
- flat monochrome line art unless specifically requested
- realistic photos
- square app badges with backgrounds
- icons with labels underneath
- icons on white backgrounds
- icons on colored cards or tiles
- mascots or characters unless specifically requested

---

## Best Practice for Future Batches

When creating new icons later, keep these defaults:

- same glossy rounded vector look
- same navy outline
- same transparent background
- same centered 1:1 format
- same level of detail
- same UI-friendly scale

If multiple icons are needed, generate them as:
- **individual files**
- **transparent PNGs**
- **consistent style across the whole batch**
