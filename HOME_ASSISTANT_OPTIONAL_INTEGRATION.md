# Optional Home Assistant Integration

School Day Grid is a standalone application. Home Assistant is an optional consumer/integration target, not the application runtime or source of truth.

## Preferred integration: MQTT Discovery

Configure a broker with:

```dotenv
SDG_MQTT_HOST=192.168.1.10
SDG_MQTT_PORT=1883
SDG_MQTT_USERNAME=
SDG_MQTT_PASSWORD=
SDG_MQTT_DISCOVERY_PREFIX=homeassistant
SDG_MQTT_BASE_TOPIC=school_day_grid
```

When configured, School Day Grid can publish retained Home Assistant MQTT Discovery definitions and state for:

- Today
- Tomorrow
- Next School Day

MQTT failure is intentionally isolated. A broker outage cannot prevent local schedule generation, the web calendar, REST API, or ICS feeds from functioning.

## REST-sensor integration

Home Assistant can also consume the standalone REST API without giving School Day Grid any HA credentials:

```text
GET /api/v1/today
GET /api/v1/tomorrow
GET /api/v1/next-school-day
GET /api/v1/schedule
```

This is a strong option when you want Home Assistant to depend on School Day Grid rather than the reverse.

## ICS subscription

Home Assistant or any external calendar client may consume the built-in ICS output. The default profile exposes `/calendar.ics`; profile-specific private feeds use:

```text
/calendar/{slug}.ics?token={ics_token}
```

Rotate a profile's ICS token from its management page if a subscription URL is exposed.

## Direct Home Assistant adapter

The direct HA adapter is retained for migration and optional compatibility. Configure:

```dotenv
SDG_HA_URL=http://homeassistant.local:8123
SDG_HA_TOKEN=<long-lived-access-token>
SDG_VERIFY_SSL=true
```

It supports:

- reading the original School Cycle Days Helpers and copying useful values into the standalone database;
- discovering HA calendars;
- optionally publishing a compatibility copy of generated events to an HA calendar;
- targeted calendar event deletion through HA's REST/WebSocket APIs where required by the legacy path.

The direct adapter does **not** become authoritative. School Day Grid's SQLite schedule remains the source of truth.

## Legacy migration

The compatibility service intentionally retains historical entity names and the marker:

```text
[school_cycle_days]
```

That makes it possible to identify and migrate/delete events generated by the old AppDaemon/Home Assistant implementation. Do not rename that marker casually; it is compatibility metadata, not product branding.

## Security

- Never commit HA long-lived tokens.
- Prefer MQTT/REST/ICS consumption when HA only needs read access.
- If `SDG_VERIFY_SSL=false` is used for a private self-signed HA endpoint, understand that TLS certificate verification is disabled for that connection.
- For a broadly distributed application, a future direct-HA setup should use a guided OAuth flow rather than asking users to paste long-lived tokens.
